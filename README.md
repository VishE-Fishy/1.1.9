# Joy Luck Club RPG Prototype

This repository now includes a full, playable single-player story RPG prototype:

- **Game file:** `joy_luck_club_rpg.py`
- **Genre:** narrative RPG with choices, stats, inventory, and turn-based combat
- **Theme:** inspired by core themes from *The Joy Luck Club*
- **Custom art/sprites:** generated procedurally inside the game using Python (no external assets required)

## Run

```bash
python joy_luck_club_rpg.py
```

## What is included

- Character sheet (HP/Chi/Spirit/Wisdom/Courage)
- Multi-chapter story progression
- Branching choices that affect stats and ending
- Turn-based battle system
- Multiple ending outcomes
- Procedural scene rendering and tile-like sprite motifs
